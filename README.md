# InterviewIQ – AI Interview Evaluator 🎯

InterviewIQ is a web application developed to help students prepare for technical interviews. It allows users to practice interview questions from different subjects, submit their answers, and check their performance. The aim is to make interview preparation easier and help students identify areas where they need to improve.

## Features

- Practice interview questions from different subjects.
- Get different questions when starting a new interview.
- Submit answers and view evaluation results.
- Check previous interview performance.
- Track progress through interview history.
- Simple and user-friendly interface.

## Technologies Used

- Python
- Streamlit
- SQLite
- Python libraries listed in `requirements.txt`

## How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/dikshitharaparla/InterviewIQ.git
```

### 2. Open the Project Folder

```bash
cd InterviewIQ
```

### 3. Install the Required Libraries

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
streamlit run app.py
```

The application will open in your web browser.

## How It Works

1. Open InterviewIQ and select a subject.
2. Start an interview and answer the questions.
3. Submit your answers for evaluation.
4. View the results and feedback.
5. Check your previous performance to understand your progress.
